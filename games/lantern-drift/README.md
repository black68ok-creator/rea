# Lantern Drift (등불 표류)

`game-studio` 스킬(`.claude/skills/game-studio/`)의 `minimal` 파이프라인으로 만든 HTML5 캔버스 게임.

- 실행: `index.html`을 브라우저로 열기 (의존성 없음)
- 조작: 마우스/터치 또는 WASD·방향키로 이동, Space·우클릭·더블탭으로 플레어, P 일시정지, M 음소거
- 설계: [`design/game-brief.md`](design/game-brief.md) · 스토리/검증: [`production/stories.md`](production/stories.md)
- 튜닝 값: `index.html`의 `CONFIG` 객체
