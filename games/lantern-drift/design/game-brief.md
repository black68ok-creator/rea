# Game Brief: Lantern Drift (등불 표류)

**One-sentence pitch:** 꺼져가는 등불 하나로 어둠 속 동굴을 떠돌며, 빛을 생명이자 무기로 써서 그림자를 태우고 반딧불을 모아 버티는 생존 게임.

## Core loop

- 어둠 속을 이동하며 반딧불을 모아 등불(빛 반경)을 채운다.
- 그림자 정령이 다가온다: 빛 안에서는 느려지고 타들어 가며, 어둠에서는 빨라진다.
- 위급할 때 **플레어**로 빛을 소모해 주변 그림자를 한 번에 태운다.
- 오래 버틸수록 점수와 난이도가 오른다 → 다시 도전.

## Player goal & fail state — what "working" looks like

- 목표: 최대한 오래 생존하며 점수(생존 시간 + 반딧불 + 처치)를 올린다.
- 실패: 빛(Light)이 0이 되면 등불이 꺼지고 게임 오버. 빛은 시간에 따라 줄고, 그림자에 닿으면 크게 줄어든다.

## MVP — what must exist to be the game

1. 이동(마우스/터치 추적 + WASD/방향키)과 빛 반경으로만 보이는 어둠 렌더링
2. 빛 감소 + 반딧불 획득으로 회복
3. 그림자 정령: 추적, 빛 안에서 감속·소멸, 접촉 시 빛 감소
4. 플레어(Space/우클릭/더블탭): 빛을 소모해 범위 내 그림자 소멸
5. 점수·시간 기반 난이도 상승
6. 시작/일시정지/게임 오버 화면과 HUD, 최고 점수
7. 손맛: 파티클, 화면 흔들림, WebAudio 효과음(음소거 M)

## Out of scope — not building this

- 맵/레벨 구조, 벽 충돌, 업그레이드·메타 진행, 음악, 온라인 랭킹, 저장(최고 점수 localStorage 제외)

## Build order

1. 빛·어둠 렌더링 + 이동 (가장 불확실한 "분위기" 검증)
2. 빛 감소/반딧불 → 그림자 정령 → 플레어
3. 난이도 곡선, 상태 화면/HUD → 손맛

---

**Who it's for / what they feel:** 5분 안팎의 짧은 판을 반복하는 캐주얼 플레이어. 어둠이 조여 오는 긴장과 플레어로 한 번에 뒤집는 해방감.

**Art & audio direction:** 거의 검은 남색 배경, 따뜻한 호박색 빛, 청록 반딧불, 보랏빛 그림자. 합성 효과음(사인/노이즈)만 사용.

**Reference game:** 서바이버류 아레나 게임의 "한 화면에서 몰려오는 적을 피하며 버티는" 루프만 차용. 자동 공격·빌드 시스템은 없음.

## Decision log (autonomous session)

- Rigor `minimal`, engine HTML5 Canvas 단일 파일 (스킬 기본값).
- 콘셉트 후보: ① 등불 표류 ② 메아리 사냥꾼(음파로 지형 탐지) ③ 중력 정원사. ①을 선택 — 빛 하나가 체력·시야·무기를 겸하는 단일 자원 설계가 가장 명확함.
