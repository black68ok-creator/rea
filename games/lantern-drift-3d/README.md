# Lantern Drift 3D (등불 표류 3D)

[2D판](../lantern-drift/)을 Three.js 3D 아케이드로 옮긴 버전. `game-studio` 스킬의 `minimal` 파이프라인으로 제작.

- 실행: `index.html`을 브라우저로 열기 (three.js를 cdnjs에서 불러오므로 인터넷 필요)
- 조작: 마우스/터치 또는 WASD·방향키 이동, Space·우클릭·FLARE 버튼으로 플레어, P 일시정지, M 음소거
- 설계: [`design/game-brief.md`](design/game-brief.md) · 스토리/검증: [`production/stories.md`](production/stories.md)
- 튜닝 값: `index.html`의 `CONFIG` 객체
