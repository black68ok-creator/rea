# Game Brief: Lantern Drift 3D (등불 표류 3D)

**One-sentence pitch:** 2D 원작의 "빛 = 생명 = 무기" 루프를 실시간 조명과 그림자가 있는 3D 아케이드 동굴로 옮긴 스코어 어택 게임.

## Core loop

- 반딧불을 모아 빛을 채우고, 빛의 고리 안으로 그림자를 끌어들여 태운다.
- 연속 획득·처치로 콤보 배수(최대 ×8)를 쌓는다. 피격 시 콤보가 끊긴다.
- 30초마다 WAVE가 올라가며 적이 빨라지고 많아진다.

## Player goal & fail state

- 목표: 하이스코어. 실패: 빛이 0이 되면 GAME OVER.

## MVP

1. Three.js 3D 아레나: 원형 동굴, 석순 기둥(충돌 + 랜턴 그림자), 하이앵글 추적 카메라
2. 랜턴 포인트 라이트 = 빛 반경, 바닥의 빛 고리로 판정 범위 표시
3. 2D판 규칙 이식: 빛 감소, 반딧불, 그림자 정령, 플레어
4. 아케이드 요소: 콤보 배수, 점수 팝업, WAVE 배너, 하이스코어
5. 상태 화면(타이틀/일시정지/게임 오버)과 DOM HUD, 터치용 플레어 버튼
6. 손맛: 파티클, 플레어 링, 카메라 흔들림, 칩튠 효과음

## Out of scope

- 여러 스테이지, 보스, 업그레이드, 온라인 랭킹, 음악

## Build order

1. 3D 조명/그림자 분위기 → 2. 규칙 이식 → 3. 콤보/WAVE → 4. HUD/화면 → 5. 손맛

---

**Art & audio direction:** 로우폴리 플랫 셰이딩, 호박색 랜턴 조명 + 보라 그림자, 칩튠 스퀘어파 효과음.

## Decision log

- 엔진: Three.js r128 UMD (cdnjs). 빌드 단계 없는 단일 HTML 유지가 목적.
- 2D판(`games/lantern-drift/`)은 보존하고 3D판을 별도 폴더로 분리.
